# 💬 Real-Time Chat App

A simple real-time chat application built using **Node.js**, **Express.js**, and **Socket.IO** to explore WebSocket-based communication.

## Features

- ⚡ Real-time messaging
- 🏠 Room-based chat functionality
- 🆔 Unique Socket ID for each connected user
- 💬 Modern chat bubble interface

## Tech Stack

- Node.js
- Express.js
- Socket.IO
- HTML
- CSS
- JavaScript

## Getting Started

1. Clone the repository

```bash
git clone https://github.com/PranjalRajJha/Chat-App.git
```

2. Install dependencies

```bash
npm install
```

3. Start the server

```bash
node server.js
```

4. Open `http://localhost:3000` in multiple browser tabs and join the same room to chat in real time.

## Learning Outcomes

- Built a WebSocket-based application using Socket.IO
- Understood event-driven communication between client and server
- Implemented room-based messaging using `socket.join()`
- Learned how Socket IDs uniquely identify connected clients
